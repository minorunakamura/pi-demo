# リバーシ — 黒の初手まで

Vite + vanilla TypeScript / HTML / CSSで動く、PC Chrome向けのリバーシです。

**この段階はCPU未接続です。** 初期表示から黒（あなた）の初手までを操作できます。着手後は反転・石数・直前の着手を更新し、白の手番で停止します。CPUは思考していません。白の手番では盤面を操作しても着手できません。CPU・Workerの接続と1局の対戦は後続Issueの範囲です。対人戦機能はありません。

## セットアップ・起動

確認基準：Node **24.21.0**、npm **11.19.0**。

```sh
npm ci
npm run dev
```

表示されたローカルURL（通常 `http://localhost:5173`）をChromeで開きます。HTMLファイルを直接開く使い方は対象外です。

## 操作

- 黒が先手。初期配置は白D4/E5、黒E4/D5で、石数は2対2です。左上がA1、右下がH8です。
- `＋` のあるD3/C4/F5/E6のいずれかをクリックするか、Tabで移動してEnter / Spaceで着手します。
- 石には「黒」「白」を表示し、直前の着手は `★` と枠、および文字で示します。
- 各マスのaccessible nameは座標と石の状態を含みます。盤面のbuttonは描画時に作り直さず、focusを保持します。
- 着手できないマスは `aria-disabled` で示し、入力も拒否します。石の状態を確認できるようTab移動の対象には残しています。
- 「最初から」で即座に初期状態へ戻ります。再読み込みでも初期化されます。保存は行いません。

## チェック・build成果物の確認

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`preview` のローカルURL（通常 `http://localhost:4173`）でbuild成果物を確認できます。`dev` / `preview` はCtrl+Cで終了します。

- `npm test`：Node標準test runnerで `tests/*.test.ts` を直接実行します。
- `npm run typecheck`：TypeScriptでbrowserとNodeテストを別々に型検査します。
- `npm run build`：Viteで `dist/` に出力します。型検査は上記の別コマンドで実行してください。

runtime依存はなく、dev依存はVite・TypeScript・`@types/node`のみです。導入バージョンはlockfileに固定しています。

### 自動テストの対象

`tests/rules.test.ts` は `src/rules.ts` の公開境界（初期化・合法手・着手/進行・手番正規化・結果）を検証します。期待値は初期配置の仕様と手計算の小局面です。

- 初期配置・両色の合法手、黒の初手と白の着手、石数・直前手・手番
- 8方向の同時反転、連続する石の反転、左右端の行またぎ防止
- 占有・挟めない・範囲外・手番違い・終局後の入力拒否、入力状態の不変性
- 黒/白の片側パスと同じ側の連続着手、満杯/空きあり双方手なしの終局、黒勝ち/白勝ち/引き分け

ルールは両色の進行から終局まで扱いますが、今回の画面は黒の初手までです。DOM mockやCPU・Workerのテストは追加していません。

### Chromeでの手動確認

`dev` と `preview` のそれぞれで次を確認します。自動テストは実Chromeでの操作・表示・console確認を代替しません。

1. 白D4/E5・黒E4/D5、2対2、黒の合法手4つを表示する。
2. 空きの非合法マス・占有マスでは変化しない。D3への着手でD4が黒になり、黒4・白1、直前手D3、白の手番となる。
3. 白の手番ではマウス/キーボードの追加着手を拒否し、「CPU未接続」と表示する。
4. Tabのfocusが見え、Enter / Spaceで合法手を選べる。着手後も同じマスのfocusが残る。
5. 「最初から」で初期化され、再び黒の初手を打てる。DevTools consoleにエラーがない。

CPU接続、CPU応答時間、1局を通した操作や楽しさは今回の実装・検証対象外です。
